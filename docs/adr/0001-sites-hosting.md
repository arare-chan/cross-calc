# ADR 0001: 計算機をOpenAI Sitesで公開する

- 状態: 採用
- 決定日: 2026-09-02

## 背景

GitHub Pages版は静的HTMLからYahoo Financeを直接読めず、複数の無料CORS中継に依存していた。中継の認証化・停止・混雑によって、銘柄コードを入力しても株価を取得できない状態が発生した。

## 決定

計算機の正規公開先をOpenAI Sitesへ移す。ブラウザは同一オリジンの `/api/quote` のみを呼び、Sitesのサーバーが固定されたYahoo Finance URLから必要な株価情報を取得する。外部の汎用CORS中継やユーザー指定プロキシは使わない。

## 結果

株価取得はCORS中継の可用性に左右されなくなる。一方、Yahoo Financeの遅延データ自体はベストエフォートであるため、取得失敗時の手入力と発注前の板確認を引き続き案内する。GitHub PagesはSites公開確認後に停止する。
