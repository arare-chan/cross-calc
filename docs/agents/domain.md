# Domain docs

## 構成

このリポジトリは単一コンテキストとして扱う。ドメイン概要、成果物の関係、共通語彙、不変条件はルートの `CONTEXT.md` に置く。詳細な取引知識と調査済みの数値は `manual/` に置き、`CONTEXT.md` へ複製しない。

## 作業前に読むもの

1. `CONTEXT.md`
2. `.claude/skills/yutai-cross/SKILL.md` が示す対象領域の `manual/`
3. 用語を追加・変更する場合は `manual/10-glossary.md`
4. 設計判断に関係する場合は `docs/adr/` の該当ADR（存在するとき）

## 用語と情報源

- Issue、コミット、コード、文書では `manual/10-glossary.md` の用語を使う。
- 数値や時刻は、マニュアルの記載より公式情報を優先する。差異を見つけたら、出典と調査日を添えてマニュアルおよび派生成果物を更新する。
- 新しい用語が必要なら、既存語の言い換えではないことを確認してから `manual/10-glossary.md` と `CONTEXT.md` を揃える。

## ADR

証券会社の一時的な料率変更や文言修正にはADRを作らない。公開方式、計算モデル、情報源の優先順位など、将来の変更を拘束する横断的な判断を行ったときだけ `docs/adr/` にADRを追加する。既存ADRと矛盾する変更は、矛盾を明示してから判断を更新する。

別の業務領域や独立アプリケーションが追加され、用語・ルール・変更サイクルを共有しなくなった場合だけ、`CONTEXT-MAP.md` と領域別 `CONTEXT.md` への分割を検討する。
